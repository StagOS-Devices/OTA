# Features
## General
* OTA Updates (Both Incremental and Full)
* Face Unlock
* Allowing to not use face unlock for secure apps using biometric prompt (By default when you enable face unlock, it will be used for secure apps too and automatically unlock them). The only way to not use face unlock for secure apps is to disable face unlock or disable biometric prompt for secure apps. This feature allows you to use face unlock for unlocking the device but not for secure apps.
