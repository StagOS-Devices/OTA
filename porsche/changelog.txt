# Features
## General
* We are trying to add something new to the QS, and one steo of the process is the transparent QS Panel (ofc you don't like it, you can disable it)
* Allow to modify the rows columns and much more of QS Tile rows and columns
* Brightness bar now has a much needed position toggle, with the default being sane bottom position
* We slightly reworked the advanced restart menu to accomodate for other actions.
* You want to beautify status bar notifications, we now allow you to use app icons (or what we call colored notification icons) or if you like it simple you can use the newly added notification counter.
* I know it's security but it could get quite annoying seeing the privacy indicators (when camera and location are on), now you can disable that.
* LTE looks lame, you can now toggle it to show 4G/4G+ instead.
* Now you can kill an app right from it's notification. Long tap on a notification to see the magic.
* And a long lost feature of stag, the clear theme or the transparent theme is now back. Go to `Settings>Display>Dark Theme>Use Custom Theme`
* For devices with variable refresh rate, now you have an option to select between different refresh rates.
* Not everyone likes the clipboard overlay (the pop up that shows at the bottom left corner on copying something). You can disable it now.
* You can enable/disable haptic feedback on volume sliders and brightness, feels more lively that way.
* QS tiles now have haptic feedback
* Center volume panel, the bottom one looks straight up ugly. We are in process of making it much better.
* Added a lot of sane defaults and under the hood smoothenss fixes
